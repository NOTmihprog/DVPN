# DVPN

**DVPN** — децентрализованный P2P VPN для частных сетей: участники за NAT, без белых адресов и без IPv6
связываются **напрямую** друг с другом, а там, где прямой путь невозможен, — через других участников сети.

Проект похож на [P2PVPN](http://www.p2pvpn.org/), Tailscale/Headscale и Yggdrasil, но без центрального
координатора: сервер обнаружения только знакомит узлы и может быть не один или не быть вовсе.

Автору DVPN решил проблему подключения к [Sunshine](https://github.com/LizardByte/Sunshine) на ПК за NAT,
а побочным эффектом упал ping в [CS2](https://store.steampowered.com/app/730/CounterStrike_2/), когда хост —
участник сети: с ~95 до ~30 мс.

> [!WARNING]
> **Ветка `DVPN-rs` — версия 4 в разработке.** Протокол v4 **несовместим** с 3.x: сеть переводится целиком
> ([переход с 3.x](doc/migration.md)). Формат конфига и CLI ещё могут меняться.
> План — [PLAN.md](PLAN.md), ход работ — [PROGRESS.md](PROGRESS.md).

## Возможности

| | |
|---|---|
| **Прямые соединения** | UDP hole punching через NAT, IPv4 и IPv6, узлы в одной LAN связываются по LAN, смена сети без разрыва (roaming) |
| **Группы и invite** | админ создаёт группу и выдаёт одноразовые invite-строки; членство подтверждает сертификат, подписанный ключом группы; исключение узла — одна команда, psk меняется без разрыва связи |
| **Шифрование** | Noise IKpsk2 (как WireGuard) + psk группы + сертификат, прямая секретность, смена ключей каждые ~2 минуты |
| **Маскировка** | ни одного постоянного байта и размера на проводе, ключи рукопожатия неотличимы от случайных (Elligator2), мусорные и «сигнатурные» пакеты в стиле AmneziaWG |
| **Mesh** | узлы, которые не видят друг друга, общаются через ретрансляторы; кратчайший путь (link-state), сквозное шифрование, автоматический переход на прямой путь |
| **Маршруты** | IPv4 и IPv6 (ULA группы) внутри сети, подсети за узлами (site-to-site), системные маршруты |
| **Выход в интернет** | каждый узел выбирает шлюзы по приоритету, весь интернет или только адреса из списка; kill switch, DNS через шлюз, NAT и NDP proxy на шлюзе, проброс портов, публичный IPv6 участнику |
| **ACL** | правила доступа внутри группы, одинаковые у всех узлов (nftables) |
| **Имена** | `phone.dvpn` (DNS) и `phone.local` (mDNS) для каждого участника |
| **Без сервера** | статические узлы с постоянным адресом; записи группы расходятся и между соседями |
| **Диагностика** | `dvpn status`, `neighbors`, `routes`, `path`, `ping`, `metrics` (счётчики трафика и отброшенных пакетов); traceroute показывает ретрансляторы |
| **API** | локальный msgpack-API для GUI, скриптов и своих протоколов поверх сети |

## Быстрый старт

Нужен сервер обнаружения на машине с белым IP (или узел с постоянным адресом — тогда сервер не нужен,
см. [статические узлы](doc/discovery.md#статические-узлы)).

```shell
# сервер обнаружения (VPS): печатает свой публичный ключ
dvpn server

# Алиса: создаёт группу, становится админом
dvpn show-key                                  # создаст config.toml
# ... добавить в config.toml [servers.main] addr / port / key сервера
dvpn group create home -n alice
dvpn group invite -n bob                       # печатает invite-строку

# Боб: входит по invite
dvpn group join <invite>

# оба
sudo dvpn
ping alice.dvpn
```

Подробно, с объяснением каждого шага, — [doc/quickstart.md](doc/quickstart.md).

## Безопасность и анонимность

DVPN предназначен для частных сетей, участники которых знают друг друга. Узел опознаётся по своему
**публичному ключу** — его можно показывать кому угодно. Секреты — **приватный ключ узла**, **секрет группы**
(у админа) и **invite-строки**: не публикуйте их и передавайте только по защищённому каналу.

DVPN не анонимизирует. Если нужна именно анонимность, используйте [Yggdrasil](https://yggdrasil-network.github.io/)
+ [WireGuard](https://www.wireguard.com/), [I2P](https://geti2p.net/) или [Tor](https://www.torproject.org/).
Подробнее — [doc/security.md](doc/security.md).

## Платформы

| | Linux | Windows | macOS |
|---|---|---|---|
| Узел, TUN, mesh, сервер обнаружения | да, покрыто тестами | да (Wintun), тесты в CI | не проверялось |
| Системные маршруты, kill switch | да | да (IP Helper) | пока вручную |
| Split DNS `*.dvpn` | да (systemd-resolved) | да (NRPT) | нет |
| ACL | да (nftables) | да (фильтр в самом узле) | да (фильтр в самом узле), не проверялось |
| Выход только для части источников (`[exit] sources`, `table`) | да | нет | нет |
| Выход только к адресам из списка (`[exit] only_file`) | да | да | пока вручную |
| Шлюз `[gateway]` (раздавать интернет) | да (nftables) | нет | нет |
| Служба | systemd | да (`dvpn service install`) | нет |

Установить можно тремя способами ([install.md](doc/install.md#три-способа)): [установщиком](https://git.mihprog.com/DVPN/DVPN-installer)
(Linux и Windows, с автообновлением), готовыми сборками для Linux (x86_64, aarch64) и Windows со страницы
[релизов](https://git.mihprog.com/DVPN/DVPN/releases) или сборкой из исходников.
Android — приложение [DVPN-android](https://git.mihprog.com/DVPN/DVPN-android) (Android 12+), iOS-клиента нет.
