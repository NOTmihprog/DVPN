# Справочник команд

[← к содержанию](../README.md#документация)

Справка по любой команде: `dvpn <команда> --help`.

## Глобальные опции

| Опция | Что |
|---|---|
| `--dir <путь>` | каталог с `config.toml` (по умолчанию — рядом с бинарником; или `DVPN_DIR`) |
| `-d`, `--disable-net` | запустить узел без TUN-интерфейса (только связь с соседями и API) |
| `-a`, `--api-addr <адрес>` | адрес API: `127.0.0.1:9902` или путь к unix-сокету — и для узла, и для команд диагностики |
| `-v`, `--version` | версия |
| `-h`, `--help` | справка |

## Узел и сервер

| Команда | Что |
|---|---|
| `dvpn` | запустить узел (нужна группа: `group create` или `group join`) |
| `dvpn server [-a адрес] [-p порт]` | запустить сервер обнаружения (по умолчанию `[::]:6485`) |
| `dvpn gen-key` | случайный ключ 32 байта (base64url) |
| `dvpn show-key [-k приватный_ключ]` | публичный ключ узла |

## Группа: dvpn group

| Команда | Что |
|---|---|
| `group create <имя> [-a адрес] [-n имя_узла] [--route подсеть]… [--relay]` | создать группу, этот узел — её админ |
| `group invite [-g группа] [-n имя] [-a адрес] [--ttl часы] [--static host:port]… [--route подсеть]… [--relay]` | invite для одного нового узла (админ) |
| `group join [invite] [-i файл]` | войти по invite (из аргумента, файла или консоли) |
| `group list` | группы узла: роль, имя и адрес, срок сертификата |
| `group members [-g группа]` | все, кто вступал: имя, ключ, адрес, срок или `revoked` |
| `group revoke <узел> [-g группа] [--in сек] [--no-rotate]` | исключить узел и сменить psk (админ) |
| `group rotate [-g группа] [--in сек]` | сменить psk (админ) |
| `group backup [-g группа] [-o файл]` | зашифрованная паролем копия секрета группы и данных админа |
| `group restore [-i файл] [--with-key]` | стать админом группы из копии |
| `group leave <группа>` | выйти из группы (удалить из `config.toml`) |

Подробно — [groups.md](groups.md).

## Участники: dvpn node

| Команда | Что |
|---|---|
| `node list [-g группа]` | участники: адреса, подсети, роли, срок сертификата |
| `node set <узел> [-n имя] [-a адрес] [--add-route P]… [--del-route P]… [--relay \| --no-relay]` | изменить участника (админ) |

Узел — имя, ключ или однозначное начало ключа.

## Доступ: dvpn acl

| Команда | Что |
|---|---|
| `acl show` | правила группы (TOML) |
| `acl set <файл>` | проверить файл и сделать правилами группы (админ) |
| `acl clear` | снять все правила (админ) |

Подробно — [acl.md](acl.md).

## Интернет: dvpn exit

```
dvpn exit [--v4 шлюзы] [--v6 шлюзы] [--none] [--kill-switch on|off] [--dns IP,…|none]
```

Без опций — показать настройки. Шлюзы — имена или ключи через запятую, лучший первым. Подробно — [exit.md](exit.md).

## Диагностика

Спрашивают работающий узел через его API (тот же `--dir` или `-a`):

| Команда | Что |
|---|---|
| `dvpn status` | этот узел: ключ, имя, группа, адреса, роль, срок сертификата, серверы обнаружения, шлюзы, kill switch |
| `dvpn neighbors` | прямые соседи: внешний адрес, RTT, жива ли связь, возраст связи, объём трафика |
| `dvpn routes` | маршруты mesh (до кого через кого, стоимость) и таблица CKR |
| `dvpn path <узел>` | путь до участника через ретрансляторы |
| `dvpn ping <узел> [-c N]` | время туда-обратно по сессии с участником (по умолчанию 4 раза) |
| `dvpn metrics` | счётчики: трафик по участникам, транзит, отброшенные пакеты по причинам |

Подробно — [troubleshooting.md](troubleshooting.md#команды-диагностики).
