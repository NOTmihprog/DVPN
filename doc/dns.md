# Имена участников: DNS и mDNS

[← к содержанию](../README.md#документация)

Каждый участник доступен по имени из своего сертификата — без настройки и без внешнего DNS-сервера.

| Имя | Ответ |
|---|---|
| `phone.dvpn` | IPv4 участника (A), его ULA-адрес и публичный IPv6, если есть (AAAA) |
| `phone.home.dvpn` | то же, с именем группы |
| `phone.local` | то же, через mDNS |

```shell
ping phone.dvpn
ssh user@nas.dvpn
ping6 phone.dvpn          # по ULA-адресу
```

## DNS-сервер узла

Каждый узел отвечает на DNS-запросы на **своём адресе в сети группы**, порт 53 (UDP). Зона собирается из
сертификатов участников и меняется сразу при `node set`, новом участнике или отзыве.

* Имена сравниваются без учёта регистра.
* Несуществующее имя внутри `.dvpn` — NXDOMAIN; имена вне зоны — REFUSED (если не задан
  [DNS через шлюз](exit.md#dns-через-шлюз)).

### systemd-resolved

Если в системе работает systemd-resolved, узел сам делает `.dvpn` **split-DNS-доменом** интерфейса туннеля
(`resolvectl domain dnet ~dvpn`): запросы `*.dvpn` идут узлу, остальные — как раньше. При остановке настройка
снимается вместе с интерфейсом.

Проверка:

```shell
resolvectl status dnet
resolvectl query phone.dvpn
```

### Без systemd-resolved

Направьте зону на адрес своего узла вручную. Например, dnsmasq:

```
server=/dvpn/10.10.33.2
```

или укажите адрес узла DNS-сервером системы (тогда остальные имена он не разрешит, пока не задан
[DNS через шлюз](exit.md#dns-через-шлюз)).

## mDNS: phone.local

Те же имена отвечают через **mDNS** как `phone.local`. Узел ставит интерфейсу туннеля флаг multicast и отвечает на
mDNS-запросы, которые система отправляет в туннель:

* avahi / nss-mdns — работают сразу;
* systemd-resolved — узел включает ему mDNS на интерфейсе туннеля.

Так имена работают и там, где DNS не настроен, — например, в программах, которые ищут хосты по `.local`.

## DNS через шлюз

Если вы ходите в интернет через [шлюз](exit.md), DNS-сервер узла может пересылать все остальные имена на
выбранные серверы через туннель — `dvpn exit --dns 1.1.1.1`. Подробно — [exit.md](exit.md#dns-через-шлюз).

## Настройки

```toml
[dns]
enable = true             # по умолчанию включено, если есть TUN
domain = "dvpn"           # зона: phone.dvpn
manage_resolved = true    # настраивать systemd-resolved (split DNS и mDNS)
```

## Имена участников

Имя задаётся при `create` (`-n`) и `invite` (`-n`), меняется `dvpn node set <узел> --name <новое>`. В DNS имя
приводится к нижнему регистру, а символы кроме латинских букв, цифр и дефиса заменяются дефисом (`My Phone` → `my-phone`). Следите, чтобы имена не повторялись:
у двух участников с одним именем DNS ответит адресами только одного из них.
