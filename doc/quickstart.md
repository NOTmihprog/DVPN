# Быстрый старт

[← к содержанию](../README.md#документация)

Пример: Алиса создаёт сеть `home` и приглашает Боба. Оба за NAT, у Алисы есть VPS с белым IP для сервера
обнаружения. Сборка и права — [install.md](install.md).

## 1. Сервер обнаружения

На VPS:

```shell
dvpn server
```

При первом запуске сервер создаёт себе ключ и печатает его в лог: `Public key: -0-goYUMWn2…`. Запомните
**IP, порт (6485) и публичный ключ** сервера и откройте входящий UDP-порт (`ufw allow 6485/udp`).
Как службу — [install.md](install.md#сервер-обнаружения-как-служба), подробности — [discovery.md](discovery.md).

> Сервер нужен только для знакомства узлов, трафик через него не идёт. Можно обойтись и без него, если у
> одного из узлов постоянный адрес — см. [статические узлы](discovery.md#статические-узлы).

## 2. Алиса: группа

```shell
dvpn show-key        # создаст config.toml с ключом узла и напечатает публичный ключ
```

Добавьте сервер в `config.toml` (серверов может быть несколько: `[servers.msk]`, `[servers.am]`, …):

```toml
[servers.main]
addr = "203.0.113.10"     # IP или доменное имя сервера
port = 6485
key = "-0-goYUMWn2jfZ2QgYhvS489mWf7G4tgS86dZK18Izo"   # публичный ключ сервера
```

Создайте группу — Алиса станет её админом:

```shell
dvpn group create home -n alice -a 10.10.33.1
```

* `-n` — своё имя в группе (по нему вас найдут другие: `alice.dvpn`);
* `-a` — свой адрес в сети (по умолчанию случайный в `10.10.33.0` с маской `[net] mask`, обычно `/24`).

Секрет группы записан в `config.toml`. **Сделайте резервную копию** — без секрета нельзя приглашать, исключать и
продлевать сертификаты, а восстановить его нельзя:

```shell
dvpn group backup -o home.bak        # спросит пароль; храните файл офлайн
```

## 3. Алиса: invite для Боба

```shell
dvpn group invite -n bob             # печатает invite-строку
```

Адрес Бобу выберется свободный (`-a` — задать самому). Invite одноразовый и действует 24 часа (`--ttl`). В нём psk
группы, профиль маскировки, серверы обнаружения и одноразовый ключ входа — **передайте его Бобу по защищённому
каналу** (мессенджер с шифрованием, лично).

## 4. Боб: вход

```shell
dvpn group join <invite>             # или без аргумента — вставить строку в консоль, или -i файл
dvpn group list
```

Серверы обнаружения добавятся в `config.toml` Боба из invite. Больше настраивать ничего не нужно.

## 5. Запуск

У обоих:

```shell
sudo dvpn
```

В логе появятся `Connection status connected` (подключение к серверу) и `Peer bob(…) new endpoint 1.2.3.4:5678`
(узлы узнали друг о друге). Узел Алисы, увидев Боба, выдаст ему постоянный сертификат и погасит invite.

```shell
ping alice.dvpn          # имена участников (или ping 10.10.33.1)
dvpn neighbors           # с кем есть прямая связь, RTT
dvpn status              # свой ключ, адреса, серверы обнаружения
```

## Что дальше

* Ещё участники — повторите шаги 3–4. Каждый invite — для одного узла.
* Доступ к домашней сети из любой точки — [подсети за узлами](routing.md#подсети-за-узлами-site-to-site).
* Интернет через VPS — [выход в интернет](exit.md).
* Узлы за строгим NAT (мобильные сети) — назначьте VPS [ретранслятором](mesh.md):
  `dvpn node set vps --relay`.
* Ограничить доступ внутри сети — [ACL](acl.md).
* Запуск как служба — [install.md](install.md#запуск-как-службы-systemd).
* Если что-то не работает — [troubleshooting.md](troubleshooting.md).
