# Переход с версии 3.x

[← к содержанию](../README.md#документация)

Версия 4 **несовместима** с 3.x ни по протоколу, ни по идентификаторам: узлы v3 и v4 друг друга не видят. Сеть
переводится целиком, серверы обнаружения тоже нужно обновить.

## Что изменилось

| | 3.x | 4 |
|---|---|---|
| идентичность узла | `peer_id`, выдаётся сервером | ключ Ed25519, id — публичный ключ |
| участники | `peers.json`, ручной обмен ключами (`export-peer` / `import-peer`) | группа, invite, сертификаты |
| шифрование | XChaCha20-Poly1305 по ключу пира | Noise IKpsk2 + psk группы, прямая секретность |
| маскировка | нет | всегда ([obfuscation.md](obfuscation.md)) |
| адрес узла | `[net] addr` | из сертификата; плюс ULA IPv6 |
| связь через других | нет | ретрансляторы ([mesh.md](mesh.md)) |
| маршруты, шлюзы, ACL, DNS | нет | [routing.md](routing.md), [exit.md](exit.md), [acl.md](acl.md), [dns.md](dns.md) |
| без сервера | нет | статические узлы |

## Порядок перехода

1. **Сервер:** обновите бинарник. Ключ сервера (`[local_server]`) сохраняется — у участников его менять не нужно.
2. **Каждый участник:** обновите бинарник. При первом запуске в `config.toml` появится `[identity]` с новым ключом
   узла. Старые `[peer] peer_id` и `[net] addr` больше не используются (их можно удалить), `peers.json` не нужен.
   `bind_addr = "0.0.0.0"` замените на `"::"`, чтобы работал IPv6.
3. **Организатор** создаёт группу (`dvpn group create`) и выдаёт каждому участнику invite (`dvpn group invite`,
   адрес можно сохранить прежний через `-a`) — см. [quickstart.md](quickstart.md). Ключи шифрования пиров из
   3.x не нужны.
4. Участники входят по invite (`dvpn group join`) и запускают узел.

## Команды

Убраны `set`, `del`, `list`, `export`, `import`, `export-peer`, `import-peer`: участников и их адреса узел узнаёт
из сертификатов. Вместо них — `dvpn group …` и `dvpn node …` ([cli.md](cli.md)).

## API

* поле `peer_id` везде заменено на `key`, запрос `get peer_id` — на `get key`;
* убраны `peer_crypto` и `crypto` в `set`;
* `peer_crypto_status` возвращает `"noise_ikpsk2"` или `"no"`;
* новые коды ошибок `key_validate_error`, `key_ambiguous`;
* новые запросы `get status`, `neighbors`, `routes`, `path`, `ping`, `metrics` ([api.md](api.md)).

Переход с 2.x (Python) описан в README тегов `v2.*` и ветки `master`; сначала переходите на 3.x.
