# Справочник config.toml

[← к содержанию](../README.md#документация)

`config.toml` лежит в каталоге данных ([install.md](install.md#каталог-данных)) и создаётся при первом запуске
любой команды. Большую часть секций пишут команды (`group create/join`, `exit`, `server`); комментарии и порядок
секций при этом сохраняются. Работающий узел подхватывает изменения `[exit]` за секунду; остальное — после
перезапуска.

Все ключи — base64url без паддинга (43 символа); обычный base64 и паддинг тоже принимаются.

## [identity]

```toml
[identity]
private_key = "..."         # приватный ключ узла (seed Ed25519), создаётся сам
```

Переменная окружения `DVPN_PRIVATE_KEY` переопределяет его. Публичный ключ (id узла): `dvpn show-key`.

## [peer]

```toml
[peer]
bind_addr = "::"            # "::" — IPv6 и IPv4 на одном сокете; "0.0.0.0" — только IPv4
bind_port = "8647-9942"     # порт или диапазон
```

Подробнее о порте и семействах — [discovery.md](discovery.md#порт).

## [servers.*]

```toml
[servers.main]              # любое количество секций [servers.<имя>]
addr = "203.0.113.10"       # IPv4, IPv6 или домен (пробуются все адреса)
port = 6485
key = "..."                 # публичный ключ сервера
```

`group join` добавляет серверы из invite. См. [discovery.md](discovery.md#сервер-обнаружения).

## [[static_peers]]

```toml
[[static_peers]]            # узлы с постоянным адресом: подключаться напрямую
key = "..."                 # ключ узла
endpoints = ["203.0.113.10:7000", "vpn.example.com:7000"]
```

`group join` добавляет их из invite (`--static`). См. [discovery.md](discovery.md#статические-узлы).

## [net]

```toml
[net]                       # если секции нет — узел работает без TUN (как с -d)
tun_name = "dnet"           # имя интерфейса (имя адаптера Wintun на Windows)
mtu = 1350                  # MTU туннеля; путь вмещает до 1420 напрямую и 1368 через ретрансляторы
mask = "255.255.255.0"      # маска сети группы или длина префикса: "24"; свой адрес — из сертификата
manage_routes = true        # ставить системные маршруты (Linux), см. routing.md
```

**MTU.** Накладные расходы DVPN — 60 байт на пакет по IPv4 (IP 20 + UDP 8 + заголовок 15 + вид 1 + тег 16), 80 по
IPv6, плюс случайное заполнение, которое урезается так, чтобы датаграмма не превышала 1452 байт. 1350 подходит
почти везде, включая PPPoE и мобильные сети. Если большие пакеты зависают — уменьшите до 1280. Подробнее —
[mesh.md](mesh.md#icmp-и-mtu).

## [[groups]]

Пишется командами `group create`, `group join`, `group restore`; руками менять не нужно.

```toml
[[groups]]
name = "home"               # локальное имя группы
id = "..."                  # id группы (её публичный ключ)
secret = "..."              # секрет группы — только у админа
psk = "..."                 # psk группы — у участников (у админа выводится из секрета)
epoch = 0                   # номер текущего psk
cert = "..."                # сертификат этого узла

[groups.obfs]               # профиль маскировки, одинаковый у всей группы
jc = "4-8"
```

Профиль маскировки — [obfuscation.md](obfuscation.md#профиль-маскировки). Пока узел может состоять только в одной
группе.

## [exit]

```toml
[exit]                      # пишется командой dvpn exit
v4 = ["vps1", "vps2"]       # шлюзы в IPv4-интернет по приоритету: имена или ключи
v6 = []                     # шлюзы в IPv6-интернет
kill_switch = true          # шлюзы заданы, но недоступны: интернет блокируется (по умолчанию)
dns = ["1.1.1.1"]           # DNS через шлюз, пока он активен
v4_sources = []             # через шлюз только эти источники (сам узел — напрямую); v6_sources — для IPv6
table = 445                 # таблица для маршрутов в интернет; без *_sources правил к ней DVPN не ставит
```

См. [exit.md](exit.md).

## [gateway]

```toml
[gateway]                   # этот узел — шлюз в интернет (Linux, nftables)
wan = ["ens3"]              # интерфейсы в интернет
ndp_proxy = "ens3"          # необязательно: публичные IPv6 участников по NDP proxy
manage_sysctl = true        # включать пересылку и proxy_ndp
```

См. [exit.md](exit.md#узел-шлюз-gateway).

## [ckr.remote_subnets]

```toml
[ckr.remote_subnets]        # свои маршруты поверх маршрутов из сертификатов
"<ключ узла>" = ["192.168.50.0/24", "~10.0.0.0/8", "!192.168.50.128/25"]
```

Синтаксис записей — [routing.md](routing.md#свои-маршруты-ckrremote_subnets).

## [dns]

```toml
[dns]
enable = true               # DNS-сервер узла на адресе в сети, порт 53
domain = "dvpn"             # зона имён участников
manage_resolved = true      # настраивать systemd-resolved: split DNS и mDNS
```

См. [dns.md](dns.md).

## [app]

```toml
[app]
log_level = "INFO"          # TRACE, DEBUG, INFO, WARNING, ERROR (CRITICAL = ERROR)
```

## [local_server]

```toml
[local_server]              # создаётся командой dvpn server
private_key = "..."
public_key = "..."          # его указывают узлы в [servers.*] key
```

## Переменные окружения

| Переменная | Что |
|---|---|
| `DVPN_DIR` | каталог данных (как `--dir`) |
| `DVPN_PRIVATE_KEY` | приватный ключ узла вместо `[identity]` |
| `DVPN_BACKUP_PASSWORD` | пароль для `group backup` / `group restore` без вопроса |

## Устаревшие параметры

`[peer] peer_id`, `[net] addr` и `[group] psk` из 3.x игнорируются, их можно удалить. В старых конфигах
`bind_addr = "0.0.0.0"` — это только IPv4; замените на `"::"`.
